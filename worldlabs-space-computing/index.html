先看结论

01｜World Labs 当前最强的是“空间重建 + 时空模拟”，还不是遥感世界模型。

Atlas 原生理解图像、视频、相机位姿与三维深度；已公开的强项是稀疏视角三维重建、显式三维输出和 Real-to-Sim（现实到仿真）。

02｜与太空算力最硬的结合点只有少数几个。

当前最值得验证的是“多视角光学遥感 + 精确成像几何 → 可验证三维场景”，以及“全球地球语义模型筛选 → 局部世界模型重建”。不建议把“Atlas 直接上星”当作核心叙事。

03｜最现实的合作不是战略联盟，而是技术基准测试。

先用海外非敏感区域、权属清晰的多视角影像做 10–20 个场景测试，只看几何精度、完整性、幻觉率、计算时间和单位成本。验证过关后再谈 API、联合开发或行业解决方案。

本材料的边界

目标中国公司在本文中统一称为“目标公司”，不出现具体名称。其能力只采用公开规划中可核验的部分：太空人工智能基础设施、模型上天、算力上天、互联互通、在轨感知—计算—决策、分钟级重访、“实时数智地球”等。

特别说明：集团/生态内已有的地球基础模型、遥感数据和星载大模型能力，不等于目标公司已经独立拥有全部能力。本文将“已公开实现”“集团生态能力”“公司规划”严格区分。
01 · 李飞飞 / WORLD LABS

她到底在做什么

核心不是“做一个更会生成视频的模型”，而是让人工智能获得对三维空间、物体关系和物理世界变化的内部表示。

图片：Stanford HAI
FACT｜已公开

从计算机视觉，走向“空间智能”

World Labs 将自身定位为“空间智能公司”。其目标是构建能够感知、生成、推理并最终与虚拟和物理世界交互的世界模型。2026 年 9 月发布的 Atlas，是其新一代全模态世界模型。

渲染器 Renderer
生成观测

给定条件和视角，生成“从这里看，世界长什么样”。

模拟器 Simulator
生成世界状态

理解空间结构与时间变化，回答“世界会怎样演化”。

规划器 Planner
输出行动

基于观察和目标决定下一步动作，闭合感知—行动回路。

ATLAS｜公开能力

Atlas 当前可确认的技术能力

  • 原生处理文字、图像、视频序列、相机位姿和三维深度。
  • 从 1 张到数十张稀疏视角图像进行真实场景三维重建。
  • 输出点云与 3D Gaussian Splat（三维高斯泼溅）等显式三维表示。
  • 进行 Space-Time Simulation（时空模拟），并支持 Real-to-Sim（现实到仿真）的机器人工作流。
  • 架构为多模态自回归扩散 Transformer（多模态序列 + 扩散生成 + Transformer）。
边界｜不要过度外推

当前没有公开证据证明

  • Atlas 原生支持 SAR（合成孔径雷达）、高光谱或多光谱遥感数据。
  • Atlas 已经用于真实卫星遥感生产任务。
  • Atlas 可直接部署在普通星载计算机上。
  • Atlas 已经能承担星座级自主规划和任务调度。
  • World Labs 已提供中国境内私有化部署。
02 · HARD FIT

与太空算力真正站得住的三个结合点

以下只保留能够从双方公开技术接口推导出的结合点；每个结合点都给出“为什么成立”和“哪里可能不成立”。

结合点 01｜最直接

多视角卫星光学影像
→ 可验证三维场景

Atlas 原生接受图像 + 相机位姿，并公开展示稀疏视角三维重建。遥感系统天然掌握轨道、姿态、相机模型和多时相/多视角影像。

技术接口
多视角光学影像 + 轨道/姿态 + 相机内参 + DEM（数字高程模型） → 坐标/相机位姿适配 → Atlas → 点云 / 三维高斯场景
价值

把“二维观测”向“局部三维世界状态”推进，适合灾区、港口、矿山、能源基础设施、工业园区等有限区域。

优先验证：高
结合点 02｜架构价值最高

全球地球语义理解
→ 局部空间重建

目标公司所在生态已经形成“地球基础模型 + 视觉基础模型 + 地球嵌入向量库”的地球智能底座；它负责全球尺度的状态表达和变化发现，而 Atlas 更适合有限区域的空间重建。

系统分工
全球遥感 → 地球基础模型筛选“哪里值得看” → 调用世界模型重建“这个地方的三维环境是什么”
价值

避免对全球海量遥感数据做高成本三维生成，把重型计算聚焦到高价值区域，更接近可行的计算经济性。

优先验证：高
结合点 03｜场景闭环

卫星发现问题
→ 现实到仿真

World Labs 已明确推进 Real-to-Sim-to-Real（现实→仿真→现实）路线。卫星适合广域发现，无人机/地面传感器适合局部补充，世界模型负责构建可交互仿真环境。

场景链路
卫星发现变化 → 无人机/地面设备补拍 → 世界模型构造三维仿真 → 机器人/无人机训练、规划和验证
价值

灾害救援、能源设施、矿山、港口等场景可形成“发现—重建—仿真—行动”链路，但卫星数据本身通常不足以支撑高精度仿真。

优先验证：中
03 · VALUE EXCHANGE

为什么 World Labs 也可能需要这种合作

合作不能只回答“我们想用 Atlas”，还要回答目标公司能给对方什么稀缺资源。

目标公司/生态可提供对 World Labs 的潜在价值需要验证的核心问题
稀疏、多视角卫星光学影像把三维重建从地面/手机场景推进到超远距离、超大尺度的观测条件。Atlas 是否能在卫星视角下保持几何稳定，而不是只生成“视觉合理”的场景。
精确轨道、姿态与相机参数提供高质量几何约束，正好对应 Atlas 原生相机位姿接口。坐标系、相机模型和地理坐标怎样进入 Atlas 空间上下文。
多时相遥感数据测试同一区域跨时间的一致性与变化建模，为“世界随时间演化”提供真实数据。是否能区分真实变化与生成漂移。
全球地球语义模型补足“全球哪里值得重建”的上游筛选层，避免 Atlas 直接承担全地球检索任务。语义嵌入怎样触发局部世界模型调用。
星上计算与在轨智能场景为 World Labs 提供一种极端边缘环境：算力、功耗、带宽、时延都受强约束。哪些 Encoder（编码器）/Task Head（任务头）能被压缩，而不要求整套 Atlas 上星。
04 · COOPERATION

可能的合作模式

建议从低风险、可证伪的技术合作开始，再逐级增加商业与资本绑定。

01

联合基准测试

用海外非敏感、多视角卫星影像验证三维重建。当前最推荐，成本低、信息增益最高。

02

Atlas 早期访问 / API

申请精选合作伙伴，使用 World API（世界模型应用程序接口）或未来 Atlas 接口集成。

03

地理空间适配层

联合开发相机几何、DEM、地理坐标、遥感元数据到世界模型空间上下文的适配。

04

行业联合方案

面向灾害、矿山、能源、港口等形成“广域发现 + 局部三维 + 仿真”的行业产品。

当前不建议把“Atlas 直接上星”或“股权/JV（合资）”作为起点。

Atlas 仍是前沿大模型且处于早期访问阶段；上星涉及算力、显存、功耗、模型权重和出口控制等多重问题。股权/JV 会把本可通过 PoC（概念验证）解决的技术不确定性，提前升级为地缘、投资审查和治理问题。

05 · ACCESS & RISK

触达路径与全量约束

这里的关键不是“能不能联系到李飞飞”，而是用什么合作命题进入 World Labs 内部，同时避免一开始触发高敏感度审查。

建议触达路径

产品/研究团队：用 Benchmark（基准测试）命题敲门

直接申请 Atlas 早期访问，题目限定为“卫星多视角光学影像 + 精确成像几何 → 三维重建”。

生态引荐：从技术伙伴而非资本伙伴切入

优先通过双方已有的芯片、云、机器人、三维工具链等生态联系做研究型引荐。

企业协议：验证后再谈数据、IP 与商业条款

重点谈“不用于训练”、数据保留/删除、输出权属、地域限制和出口合规。

商业方案：只在指标过关后进入

先证明客户愿意为“三维状态/仿真结果”付钱，再谈联合行业方案或长期绑定。

风险与影响因素

遥感数据出境高

中国境内观测遥感数据未经授权不得向境外组织或个人提供；商业遥感活动亦参照相关规则管理。

训练与数据二次使用高

World Labs 现行条款允许使用用户内容改进/训练模型；付费用户可前瞻性退出，但需要企业合同重新约定。

双用途属性高

遥感、卫星自主决策和高精度空间重建具有明显军民两用属性，使用场景决定审查强度。

美国出口控制高

越靠近模型权重、先进算力、训练基础设施和敏感最终用途，合规复杂度越高。

中国一般数据跨境中

重要数据、个人信息等仍需按数据出境规则履行相应义务；与遥感专门规则叠加考虑。

模型私有部署能力中

当前公开资料未证明 World Labs 提供中国境内私有部署，这会影响敏感数据可用性。

商业 ROI中

三维世界模型计算成本高，若输出只是“更好看的三维场景”，无法支撑高价值 B2B 付费。

技术匹配度中

光学影像结合点最强；SAR/高光谱/多光谱目前缺少公开接口证据。

API/PoC 合作相对低

使用海外非敏感数据、限制用途、只做地面端测试，可显著降低初期政策和地缘摩擦。

股权/JV高

会叠加外资审查、对外投资/国家安全审查、治理和长期地缘不确定性，不适合作为第一步。

06 · BEYOND WORLD LABS

从 World Labs 扩展到“世界模型 × 太空算力”

地理空间基础模型不等于世界模型，但已经形成从“表征世界”走向“理解、预测、行动”的技术阶梯。

这条链路里，L1–L3 已经有公开案例；L4–L5 才是真正意义上世界模型开始进入太空系统的部分。
AE

AlphaEarth Foundations

把多源、多模态地球观测数据统一成紧凑地理空间嵌入，用机器可读方式表达“这个地方是什么、怎样变化”。

已发布 / 地面端
PV

Prithvi

NASA / IBM 地理空间基础模型的压缩版本已被部署到两个在轨平台，验证基础模型上星。

2026｜已在轨验证
Φ2

ESA Φsat-2

星上 AI 执行云筛选、灾害分析、船舶检测、图像压缩等任务，证明“可编程在轨 AI”正在形成。

2025｜科学运行阶段
DT

NASA 动态目标选择

卫星在不到 90 秒内完成前视观测、在轨分析、判断和重新指向，证明感知—行动闭环可在轨运行。

2025｜飞行验证

长期价值不一定是“卫星算更多”，而可能是“持续维护机器可读的世界状态”。

当多星、多传感器、星间网络和在轨 AI 逐步成熟，价值链可能从“影像/数据 → 分析结果”继续迁移到“状态 → 预测 → 决策 → 再观测”。

现实世界→卫星持续观测→在轨理解→更新世界状态→模拟 / 预测→重新调度观测
07 · NEXT MOVE

最小可行验证：只回答一个问题

不做宏大战略先行。用一个可证伪的技术问题决定是否值得继续投入。

建议

Atlas 能否用卫星稀疏多视角影像，重建“可测量”而不只是“看起来合理”的真实三维场景？

样本选 10–20 个海外非敏感区域。输入多视角光学影像、轨道/姿态、相机参数、DEM 和可用于比对的三维基准；输出点云/三维场景并进行误差审计。

几何误差位置、深度、形变
尺度准确性绝对尺度是否可信
场景完整度已观测区域覆盖率
幻觉率未观测区域虚构程度
计算时间单场景端到端耗时
单位成本每平方公里/每场景成本

Go / No-Go 逻辑

若几何精度不够

把 World Labs 保留为创意/仿真工具，不纳入核心遥感智能链路。

若几何精度可接受、但成本高

只用于高价值局部区域，由地球基础模型先筛选再调用。

若精度与成本同时过关

进入第二阶段：多时相一致性、变化建模、行业场景和联合产品化。
